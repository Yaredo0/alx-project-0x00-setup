# alx-project-0x00

This project is part of the ALX Software Engineering curriculum. It sets up a modern web development environment using:

- ✅ [Next.js](https://nextjs.org/) – React framework for production
- ✅ [TypeScript](https://www.typescriptlang.org/) – Static typing for JavaScript
- ✅ [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework
- ✅ [ESLint](https://eslint.org/) – Linter for code quality
- ✅ Import alias `@/*` – Simplified path imports
